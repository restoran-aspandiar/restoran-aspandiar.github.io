# Aspandiar — банкетный ресторан в Атырау

Лендинг на казахском, русском и английском языках.

Четыре банкетных меню: 5 000, 7 000, 8 000 и 10 000 ₸ на гостя. Сравнение состава меню, фотографии, предварительный выбор салатов и горячего, расчёт стоимости, WhatsApp и маршрут.

Телефон администрации: +7 702 000 80 30. Адрес: Атырау, ул. Шукыр Еркинов, 77а.

Некоторые изображения обозначены как «Пример подачи»: это иллюстрации, не фотографии блюд ресторана. Конкретные варианты, состав, порции и доступность подтверждает администрация. Ссылки WhatsApp подготавливают сообщение, но не отправляют его автоматически.

## Размещение на GitHub Pages

Сайт не требует сборки. Источник публикации: ветка `main`, папка `/` (корень). Файл `.nojekyll` сохраняет обычную статическую публикацию. Все ресурсы используют относительные пути, поэтому сайт работает и по адресу репозитория GitHub Pages.

Для обновления загрузите изменённые HTML, CSS, JavaScript и фотографии в этот репозиторий.
